# 1.0.01

- 关于页仅保留版本号和“检查更新”，内容居中，保留返回操作；移除可见图标、说明文字和反馈按钮。
- 音乐接口升为 API v3，兼容此前 67 项，合计 76 项入口。
- 新增每日热歌、每日回顾、歌曲电台推荐、首页分类歌单、歌单分类、分类下歌单和推荐专辑。
- 新增当前歌曲的逐字歌词时间轴和当前字块接口，复制原生 LRCX 数据；无逐字时间时回退普通歌词，不推算字时间。
- 增加 [其它 App / AI 对接指南](https://github.com/cxcboss/kuwo-music-car/blob/main/sdk/其它App对接指南.md)，附参数、返回类型、分类调用顺序、歌词高亮和错误处理说明。
- versionCode 递增为 74001，沿用同一包名、签名和 GitHub 更新源。更新文件名为 `1.0.01-酷我音乐.apk`。

## 本版已完成的验证

- 编译、签名、对齐及 342 项结构检查通过，包含 131 个宿主反射方法符号。两个方向的关于页资源均只保留可见版本号和更新控件。
- 驻车车机覆盖安装成功，同 UID Provider 实际返回 1.0.01 / 74001、API v3 和 76 项入口，服务 READY、autoPlay=false。
- 新增的 7 个在线推荐/目录方法均实际返回成功：热歌 30 首、回顾 29 首、歌曲电台 5 首；首页分类歌单集合 72 项、分类集合 73 项、推荐专辑集合 70 项。分类 → 歌单 → 歌曲链路读取成功。
- 当前暂停歌曲《不浪漫罪名》实际返回 LRCX 及 480 个字块，当前字块接口可读。错误歌曲引用和旧修订号分别返回 STALE_TRACK / STALE_LYRICS。
- 使用原包歌词类的独立快照检查通过：全局偏移、UTF-16 字符区间、零时长字块、跨行及普通 LRC/失败结果回退。样例数据未注入运行中的歌词缓存。
- 读取检查前后播放器均为暂停状态，没有通过接口启动播放。
- 车机实际“关于”页已核对，只显示居中的 `1.0.01` 和“检查更新”，返回箭头可用；无旧说明和反馈按钮。

## 验证限制

尚未在其它客户端 App 中完成播放中逐字高亮的视觉验收。本次数据读取成功不代表会员歌曲可播放，也不代表上游旧接口持续可用；每日热歌和回顾在原包中已被标记为 deprecated。

没有执行真实断电开机、点火/休眠周期、道路或声音播放验证。测试、设备日志及构建产物全部位于项目外。

此前 1.0.0 证明了 GitHub 清单检测、完整本地包校验及系统覆盖安装，但车机直接从 GitHub 完整下载曾因 EOF 网络中断失败；本版未修改下载传输或重复宣称完整 OTA 通过。固定保存目录和手动安装兜底继续保留。

历史版本及其验证记录见 [1.0.0 Release](https://github.com/cxcboss/kuwo-music-car/releases/tag/v1.0.0)。
