# 1.0.0

- 从此前精简接口版建立独立发布版本，versionCode 74000。
- 移除启动广告视图及固定跳转等待，保留原隐私和账号初始化。
- 完善后台及开机静默启动，使用原音乐前台服务，不自动播放。
- 关于页接入本仓库正式 Releases，支持检查、下载及系统安装。
- 更新包保存到内部存储 `000/酷我音乐更新/1.0.0-酷我音乐.apk`，保留手动安装兜底。
- 保留 67 项同机音乐接口，整理源码、构建发布脚本及 AI 接手文档。

## 已完成的验证

- APK 构建、签名、对齐及 322 项结构检查通过，包含 117 个宿主反射符号。
- 原有 83 项主机策略/反射断言通过；车机上 10 项更新清单校验及匿名 GitHub 清单读取通过。
- 驻车检查中，“关于”页正常显示 1.0.0，检查更新按钮可打开内部更新页并发现正式版本。
- 同 UID 接口可读取应用版本、67 项能力清单及当前歌曲状态。启动配置已开启，状态为 `serviceReady=true`、`autoPlay=false`，未触发播放。
- 覆盖安装后的正式包再次通过同 UID 接口和启动处理路径检查，返回版本 74000、服务 READY、静默启动开启且不自动播放。
- 正常打开应用再返回桌面后，原 MainService 仍处于 `isForeground=true`、`startRequested=true`，通知无声音和振动。验证辅助包与本轮设备临时文件已清理，指定目录中的正式安装包保留。
- 在受控检查中调用实际 BootReceiver 的开机处理路径，原音乐前台服务进入 READY。此项是启动逻辑验证，不等同于车机真实断电开机。
- 正式 APK 经 ADB 复制到 `000/酷我音乐更新/1.0.0-酷我音乐.apk`，车机上的文件哈希、包名、版本及签名检查通过。通过验证辅助程序将该已校验文件交给应用自身的 FileProvider/安装方法，系统安装器完成覆盖升级，车机版本为 1.0.0 / 74000。
- 正式版“关于”页显示 1.0.0 / 74000，访问 GitHub 正式清单后正确显示“已是最新版本”。已安装 APK 的 SHA-256 与发布附件一致，为 `41e3a362203a205727cb7286859f81e380fedf0d744e421c429c7aa42dbf8448`。
- 车机屏蔽安装来源设置页，本轮使用已授权 ADB 为本应用单独配置 `REQUEST_INSTALL_PACKAGES=allow`，系统安装确认仍保留，配置方法见更新机制说明。

## 性能与验证限制

已移除广告视图、完成轮询、固定 100ms 跳转及原厂远程热修复初始化开销。新版强制停止后拉起主界面的抽样约为 4.4 秒；旧版采样有的返回 WelcomeActivity，且受到 CabinDeck 窗口切换影响，测量终点不一致，不据此给出提速百分比。

未执行真实断电开机、点火/休眠周期、道路或声音播放验证。设备日志、检查代码、临时 APK 和历史构建均在项目外，未提交到仓库。

车机直连 GitHub 的完整下载本轮未通过：一次下载推进至半程以上后失败，重试捕获到读取 HTTP 响应时的 EOF 网络中断。因此本轮证明了清单检测、部分网络传输、完整本地发布包校验及系统覆盖安装，不能将它们写成完整 OTA 全链路通过。保留指定目录中的正式安装包作为本机安装兜底。
