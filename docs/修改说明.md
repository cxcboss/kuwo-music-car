# 修改说明

## 1.0.0 新增及调整

- 将显示版本及原 `KwApp` 版本读取统一为 1.0.0，Android 内部版本码 74000。
- “关于”显示新版本号，启用原隐藏的检查更新按钮，进入本项目的 GitHub 更新流程。
- 更新校验、下载、安装、固定文件名和目录见 [更新机制](更新机制.md)。
- 冷启动保留原隐私、账号初始化及 Intent 传递，直接进入主界面；移除启动广告视图创建、广告完成轮询和固定 100ms 跳转等待。
- 停止原 RFix 客户端远程补丁检查，保留原 Application 代理启动框架，避免原厂热修复覆盖本项目补丁；新的 APK 更新统一走本仓库。
- 后台启动在 Android 8+ 明确调用 `startForegroundService`，原 `MainService` 创建无声、低优先级通知；保留原 `START_STICKY` 返回值，并明确 `stopWithTask=false`。
- 整理为源码、构建脚本、SDK、配置及文档目录；构建结果和验证数据保存在项目外。

## 沿用的精简和性能修改

- 首页仅保留“我的、推荐、乐库”，标签按内容居中，移除“甄选、听吧”和全息声音场景。
- 播放页面移除伴唱、音质、音效、动效、MV、下载入口；停止对应初始化和任务入口。保留原在线播放缓存。
- 我的页面过滤本地、下载、云盘、会员中心和推广；搜索分类去除视频、听书。
- 停用已定位的推广请求及客户端统计、广告统计、ATTA、XLog 自动上传路径，保留必要本地诊断。未据此宣称所有第三方 SDK 均无网络上报。
- 搜索联想防抖 300ms，取消旧请求并过滤过期回调。
- 首页刷新合并、成功结果短时缓存，隐藏页面延后绑定及应用数据，隐藏时暂停推荐动画。
- 播放封面解码限制尺寸，公共列表取消条目变更动画，减少重复查找 View 和反射成员。
- 同机音乐接口 v2 保留 67 个方法及旧版兼容入口。

原类、资源和共享 native 库仍保留，未声称包体体积明显缩小。

## 后台与开机启动

监听 `BOOT_COMPLETED` 和 `MY_PACKAGE_REPLACED`。默认启用，配置与原设置页及 `setStartupConfig` 接口一致。首次安装必须手动打开并完成原隐私确认。

启动只准备原音乐服务，不打开页面、不自动播放。退出任务时保持服务可运行，服务被系统回收后可由原黏性服务机制重建。用户强制停止、关闭启动开关、厂商后台限制均需遵循系统规则，不做循环拉活。

当前目标车机为 Android 10（API 29），安装及运行验证需在驻车条件下进行。没有通过重启真实车机验证的行为，不能写成已验证开机自启。

## 对外接口

入口为 `ContentProvider.call()`，authority `cn.kuwo.kwmusiccar.bridge`。同 UID 及白名单客户端可访问。完整字段、请求与错误码见 [接入说明](../sdk/接入说明.md) 和 [JSON 合同](../sdk/api-contract.json)。

接口覆盖能力/版本、后台初始化与启动配置、状态/歌曲/封面/歌词、播放控制与模式、队列、收藏、用户歌单、搜索和在线曲库、整机媒体流音量。保留原登录和内容权限。

客户端源文件为 `sdk/KuwoBridgeClient.java`。响应中的 `accepted` 表示命令被接受，不能作为已经出声或云端修改完成的证据。封面使用受限 PNG URI 读取，不跨 Binder 传送 Bitmap。
