# 构建与发布

## 工具与输入

- Python 3.10+、JDK 17+、Apktool 2.12.1；`python3`、`javac`、`java`、`apktool` 位于 PATH。
- Android SDK：`platforms/android-35/android.jar`、`build-tools/36.1.0`。
- SDK 路径取 `ANDROID_HOME`，macOS 默认 `~/Library/Android/sdk`。
- 原始 APK 的固定 SHA-256 见 `config/version.json`。
- 既有签名材料：`kuwo-lean.jks` 和 `password.txt`，别名 `kuwo-lean`。

默认密钥目录 `~/.local/share/kuwo-music/signing/`，也可用 `--keys /外部/密钥目录` 指定。密钥目录及文件权限分别建议 700 和 600。不能生成新密钥冒充旧签名，不能把口令写入命令参数、日志或仓库。

## 构建

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
python3 scripts/build.py --base-apk /外部/原始酷我.apk
```

可用 `KUWO_BASE_APK` 环境变量代替 `--base-apk`。`--output` 指定项目外的构建结果父目录，默认 `~/.cache/kuwo-music/builds/`。每次新建时间戳目录，包含最终 APK、更新清单、哈希清单、构建收据和过程日志。

构建入口验证原始哈希后临时解包，应用补丁、编译注入代码、重建资源、对齐、使用既有证书签名。然后执行签名、对齐和 `verify_build.py` 结构检查。所有 native 库保留原字节内容。

## 下一次更新

```bash
python3 scripts/bump_version.py
# 完成代码修改，并更新 docs/版本更新.md 的当前版本说明
python3 scripts/build.py --base-apk /外部/原始酷我.apk
git add src scripts config sdk docs README.md AGENTS.md .gitignore
git commit -m 'Release 1.0.01'
git push origin main
python3 scripts/publish.py --build /外部/本次构建目录
```

递增规则：revision 加 1，显示版本 `1.0.01、1.0.02…`，versionCode 加 1。原始 `1.0.0` 对应 revision 0、versionCode 74000。

发布脚本要求本地提交干净、构建版本和配置一致，并核对 APK 哈希，随后创建正式 Release。附件自动上传 APK、`update.json` 和 `SHA256SUMS`。使用 GitHub CLI 当前登录账号，无凭据进入 APK。

## 仓库约定

仓库为公开 `cxcboss/kuwo-music-car`，Description、About 简介和 Homepage 保持为空。README 及项目文档照常维护。原始 APK 和历史数据归档在项目外，发布二进制仅放 Releases。

发布完成后匿名请求更新清单并核对对应 APK 哈希。设备验证需要真实授权及驻车条件，不自行重启车机。
