# 酷我精简版同机音乐接口 v2

适用 APK：**1.0.0 / 74000 起**，包名 `cn.kuwo.kwmusiccas`，Provider authority 保持 `cn.kuwo.kwmusiccar.bridge`。v1 的通用 request 和既有方法保留；新增字段采用可缺省方式扩展。1.0.0 延续接口 v2 的 67 个方法；本项目没有修改 CabinDeck 工程。当前设备验证范围见 `docs/版本更新.md`。

## 快速接入

默认允许 `com.cabindeck` 及酷我自身 UID。其他同机 App 把实际安装包名加入音乐 APK 的 `config/bridge_clients.txt` 后重新打包；调用方通过 Binder UID 核对，不能以请求参数伪装包名。现有其他导出服务不属于本接口白名单合同。

复制 `KuwoBridgeClient.java` 到客户端，保留 package 或调整 import。客户端 Manifest 增加：

```xml
<queries>
    <provider android:authorities="cn.kuwo.kwmusiccar.bridge" />
    <package android:name="cn.kuwo.kwmusiccas" />
</queries>
```

```java
KuwoBridgeClient client = new KuwoBridgeClient(context);
client.getCapabilities(result -> { /* inspect apiVersion and methods */ });
client.initialize(result -> { /* inspect serviceReady, then read state when ready */ });
client.getState(result -> {
    if (!"OK".equals(result.getString("status"))) return;
    Bundle state = result.getBundle("state");
});
```

每次 request() 返回唯一请求 ID，实际响应在客户端主线程异步回调。SDK 自动加 requestId 和 ResultReceiver，最多等待25秒且每个请求只回调一次；关闭后待处理请求以 CLOSED 完成。底层同步 ACCEPTED 仅表示已入队；capabilities 的同步 OK 也由 SDK 统一交付为一次回调。

除能力、版本、启动配置/状态、initialize、取消请求外，其他方法要求已同意原隐私协议、主音乐服务就绪。首次安装后需要手动打开酷我并完成隐私确认；账号相关操作仍要求原账号登录。initialize 不替用户同意协议或打开登录页面。

## 数据类型

- **Song**：index:int、trackId:string、title/artist/album:string、artistId/albumId:string、durationMs:long、trackKey:string、coverUrl:string、artworkUri:string。ID 统一为字符串；无数据的图片地址为空串，不伪造封面或歌曲。durationMs 为毫秒。
- **PlaybackState**：state:string（沿用原播放器状态名，例如 PLAYING/PAUSE/STOP/BUFFERING/INIT/FAILED）、playing:boolean、contentType:int、positionMs:int、durationMs:int、mode:string、song:Song、trackKey:string、activeQueueIndex:int、updatedAtElapsedMs:long、revision:long。时间戳为宿主读取快照时的单调时钟，不能视作原播放事件时间；客户端按自己的单调时钟推算进度，seek/暂停/切歌后重新读。
- **CatalogItem**：id:string、name:string、coverUrl:string。仅已核实的目录基础字段；封面 URL 不存在时为空，不假定所有专辑/歌手都带图片。
- **LyricLine**：startMs:long、durationMs:long、text:string。text 最多1024字符，resultCode=20000 才视为上游歌词成功。
- **SongRef** 为 Bundle，三种来源：当前歌曲 `{trackKey}`（key 可省略）；列表项 `{listId,revision,index}`；异步结果项 `{resultRequestId,index}`（也兼容 searchRequestId）。`songRef` 参数用 putBundle，songRefs 用 putParcelableArrayList，不传酷我私有 Parcelable。

列表中的 index 为整列表绝对下标，搜索/在线曲库结果中 index 为该结果页下标。队列和歌单的 revision 为字符串；歌词/状态/封面 revision 为 long，不要混用。列表 revision 变化后重读，不能只凭同一个歌曲ID继续使用旧下标。空白/未就绪数据应清空对应视图，不能沿用上首歌曲。

```java
Bundle ref = KuwoBridgeClient.resultItem(resultRequestId, 0);
client.setFavorite(ref, true, result -> { /* use favorite and stateConfirmed */ });
Bundle play = new Bundle();
play.putString("resultRequestId", resultRequestId);
play.putInt("index", 0);
// Call after the user chooses the song:
client.request("playResultItem", play, result -> { /* accepted is not audible playback proof */ });
```

## 分页与结果保留

page 从0开始，范围0..10000；pageSize 默认30，范围1..50。搜索与在线曲库的 hasMore 是估计值，不是准确服务端总数；空页后停止翻页。truncated=true 表示宿主页超过传输上限，不应显示“全部已加载”。每日推荐采用宿主固定页大小；榜单先按宿主分组分页、再展平，不承诺一次枚举所有条目。

搜索和在线曲库共用配额：每 UID 最多2个并发，全局8个，20秒上游等待超时。返回歌曲的结果页每 UID 保留2页、全局16页，120秒到期。后续请求会淘汰旧页；因此保存 resultRequestId 只用于近期交互，不能作为长期歌单存储。超时、取消、进程重启或被淘汰后重新获取。

本机列表固定 ID 为 queue、favorites、history；其他列表用 getLists 返回的 named: 编码标识，不能自行拼未加载列表名。只枚举当前已加载的音乐列表，不枚举内部缓存、下载、本地或云盘。getPlaylistInfo 说明可写能力；只有用户创建列表可重命名、删除、修改歌曲，收藏用专用接口。queue 当前来自其他不可写列表时，修改返回 READ_ONLY_LIST；先用 playQueue 走原宿主替换队列后再查询实际类型。没有额外开放任意数据库、文件、账号凭证或音频直链。

## 封面对接

当前歌曲的 song.coverUrl 是原歌曲数据中的 HTTP(S) 图片 URL，可能为空；song.artworkUri 是宿主已发布到 MediaSession 的缓存图片 URI，也可能为空。getArtwork 会尝试获取原播放器当前缓存的封面，不发起额外图片下载。其图片可能沿用原宿主的占位封面；available 只表示可读取图片，不表示已核实为专辑原图。

封面不直接放进 Binder Bundle。用 ContentResolver.openInputStream(artworkUri) 或 SDK readArtwork，在 IO 线程读取 PNG。size 参数为64..1024的最长边，默认512，等比例缩小且不放大；获取头返回的 width/height 是宿主缓存原尺寸。读取仍核对 UID 白名单和原隐私状态。

```java
client.getArtwork(result -> {
    if (!"OK".equals(result.getString("status"))) return;
    String key = result.getString("trackKey", "");
    String uri = result.getString("artworkUri", "");
    if (uri.isEmpty()) { /* clear cover / use the app's own empty state */ return; }
    imageExecutor.execute(() -> {
        try {
            android.graphics.Bitmap cover = client.readArtwork(uri, 512);
            mainHandler.post(() -> {
                if (key.equals(currentTrackKey)) albumImage.setImageBitmap(cover);
            });
        } catch (java.io.IOException error) {
            // The URI may have expired; re-read getArtwork, with bounded retries.
        }
    });
});
```

示例中的 imageExecutor、mainHandler、currentTrackKey、albumImage 由宿主卡片拥有。异步加载完成前必须再次核对 trackKey，避免切歌后显示旧图。封面 URI 随新缓存图失效，不能永久保存；收到封面通知后重新获取。此接口不提供任意 URL 代理、私有文件读取或已移除的音频下载。

## 通知与卡片交互

订阅 content://cn.kuwo.kwmusiccar.bridge 下四个子路径：state、lyrics、artwork、lists。SDK Listener 的 onArtworkChanged/onListsChanged 是兼容默认方法，可单独覆写；通知只有变化信号，收到后读取对应接口。状态和列表通知会合并，客户端也应合并正在读取的同类请求，避免高频轮询。

连接后先读取 state、lyrics 和 artwork，再依赖通知。歌词按原歌词回调变化，不逐帧广播；当前行由 positionMs 及时间轴推算，或按需 getCurrentLyric。列表通知包括新接口变更与已接入的原列表增删路径，不承诺所有远程同步来源实时通知；重新显示卡片时重读。

控制命令返回 accepted，仅说明交给原控制器，不代表真正开始播放。通过状态通知、getState 和现场听音分别确认。收藏、音量等 stateConfirmed 仅是软件状态读回，也不代表云端同步或实际扬声器输出。

## 开机与静默启动

默认开启。已有设置页的开机启动开关与 setStartupConfig 共用一份配置。接收 BOOT_COMPLETED 和自身 MY_PACKAGE_REPLACED 后，已同意隐私且开关启用时调用原 MainService.h，以 isAutoPlay=false 准备后台服务；不调用 startActivity，不自动跳到前台，不请求音频播放。用户点击系统音乐通知仍可主动打开应用。

保留 Android 前台音乐服务必需的系统通知：无声、低优先级、不震动，不添加说明性页面。静默不等于隐藏系统服务通知。没有额外常驻保活线程、无限重试、定时拉起或强制取消用户的停止操作。

若返回 initialize accepted=true/stateConfirmed=false，按 getStartupStatus 的 serviceReady 确认连接；可做有限次短间隔重读，15秒仍未就绪则向调用层报告，等待下一次用户动作。系统后台启动限制可能使请求返回 START_BLOCKED/NOT_READY，不提供“保证永远自启”的承诺。首次安装未打开、用户强制停止、隐私未同意或厂商限制均可能阻止启动。

适配目标仍是现有 Android10 车机（原包 targetSdk34 不变）。Android 新版本有后台启动和前台服务类型限制，后续迁移须另核验；依据：[后台前台服务限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)。

## 错误码与生命周期

- OK：实际请求已处理；是否生效看 accepted、stateConfirmed 及后续状态。
- ACCEPTED：只入队，等待 ResultReceiver；SDK 已处理这个阶段。
- FORBIDDEN：调用 UID 不在白名单。PRIVACY_REQUIRED：原隐私确认尚未完成。LOGIN_REQUIRED：账号操作需要正常登录。
- NOT_READY / START_BLOCKED：服务尚未连接或后台启动被拒。NO_TRACK / NOT_FOUND：无当前歌曲或对象不存在。
- INVALID_ARGUMENT / INVALID_REQUEST_ID / CALLBACK_REQUIRED：参数、ID 或底层回调错误。
- BUSY / DUPLICATE_REQUEST：配额或重复请求ID。TIMEOUT / CANCELLED：超时或取消。
- STALE_LIST / STALE_TRACK / STALE_SEARCH：列表、当前歌曲引用或结果页已过期。STALE_SEARCH 同时用于在线曲库歌曲结果页。
- READ_ONLY_LIST：目标列表不可通过此操作修改。UNSUPPORTED / UNSUPPORTED_CONTENT：不支持的接口或当前内容。OPERATION_FAILED：原列表操作拒绝。
- SEARCH_FAILED / UPSTREAM_ERROR：原搜索/曲库服务失败；upstreamCode 若存在为原错误码。
- SDK 还可能返回 CLOSED / UNAVAILABLE / EMPTY_RESPONSE。图片读取失败以 IOException 表示，URI过期时重新获取一次，避免无限重试。

调用方销毁时执行 client.close() 并释放自己的图片 executor/Bitmap。取消服务端网络工作时，在 close 前发送 cancelRequest；本地超时/close 本身不等于服务端任务已取消，服务端最多20秒超时后释放。用户明确触发列表删除、清空、音量或播放操作时再调用对应方法，不在重连或刷新时重放写操作。

本版开放保留的音乐能力；之前移除的广告推广、伴唱、音质/音效、动效、MV、下载、云盘、本地音乐入口不恢复。会员购买、权限绕过和私有账号数据不属于音乐接口。接口机器清单见 api-contract.json。

请求超时不代表已入队的写操作被撤销；应先读取实际状态，不自动重发切换、删除等非幂等操作。
